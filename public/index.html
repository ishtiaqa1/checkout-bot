Stock detection (recommended: external)

Can't Follow Discord channels? Use Fast API monitor — one Target tab checks all 18 products every ~1 second during drops. Auto-checkout, no manual clicking.

  1. Create a personal Discord server (free)
  2. In Pokémon Restocks and Alerts, open the Target restock channel → click Follow (bell) → choose your server
  3. Create a bot at discord.com/developers → enable Message Content Intent → invite bot to your server
  4. Enable Developer Mode in Discord → right-click the mirrored channel in YOUR server → Copy Channel ID
  5. Paste token + channel ID below → Save → Stop → Start
